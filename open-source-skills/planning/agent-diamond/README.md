# agent-diamond

Design multi-agent workflows with the diamond pattern: parallel researchers, independent skeptics, then a human approval gate.

**Use it when:** Building agent graphs, research desks or content pipelines.

**Notes:** `references/one-pager.md` is a quick reference card.

## Install

```bash
cp -R agent-diamond ~/.claude/skills/
```
