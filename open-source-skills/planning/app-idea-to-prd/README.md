# app-idea-to-prd

Turn a rough idea (even a voice-note transcript) into a PRD with quick, honestly-sourced market research and a build/park/skip verdict.

**Use it when:** Capturing app ideas fast, e.g. from your phone.

**Notes:** Set `IDEAS_DIR` (and optionally `MOC_FILE`) at the top of the skill to choose where notes are saved.

## Install

```bash
cp -R app-idea-to-prd ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
