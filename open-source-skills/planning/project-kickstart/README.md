# project-kickstart

A 7-phase, gated planning pipeline from raw idea to launch: offer and market, PRD, foundation docs, roadmap, epics, sprints, PR workflow, launch.

**Use it when:** Starting any new app, site or software project.

**Notes:** Creates real planning files in your project folder and waits for your approval between phases.

## Install

```bash
cp -R project-kickstart ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
