# lead-research-outreach

Build a short dossier on each prospect from public information and draft a value-first email sequence for you to review and send.

**Use it when:** You do outbound and want personal, honest outreach instead of templates.

**Notes:** Draft-only; includes compliance reminders (CAN-SPAM, GDPR). Not legal advice.

## Install

```bash
cp -R lead-research-outreach ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
