# App Store asset pre-submission checklist

Mark each item PASS / FAIL / N/A. Cite the rule source for any FAIL.

## Technical (run scripts/validate_assets.py)
- [ ] Icon 1024x1024 PNG, no alpha
- [ ] Required screenshot sizes present: iPhone Dynamic Island medium (or larger set that falls back), iPad 13" if iPad supported, Mac/TV/Vision/Watch if applicable
- [ ] 1-10 screenshots per device size; JPEG/PNG; no alpha
- [ ] Portrait/landscape consistent with the UI shown
- [ ] Previews 15-30 s, <=500 MB, H.264/ProRes, <=30 fps, accepted resolution, stereo AAC
- [ ] Preview aspect ratio matches screenshots (else lands in "A Closer Look")
- [ ] Creative assets match exact size/aspect table, no alpha

## Content: all assets
- [ ] No prices, discounts, URLs, copyright symbols
- [ ] No unverifiable claims; no Apple recognitions (Editor's Choice, App of the Day, ADA)
- [ ] No other platforms/marketplaces (Android, Google Play, etc.) or competitor references
- [ ] Appropriate for 4+ (no gore, weapons aimed at people, suggestive/drug/profanity content)
- [ ] Fictional/sample data only; no real person's info; rights cleared for all imagery, fonts, music
- [ ] Inclusive, globally appropriate imagery
- [ ] Matches the current shipping UI/version
- [ ] Consistent palette, fonts, iconography, tone across the set
- [ ] Key elements legible at thumbnail size; focal point centered; text inside safe area

## Screenshots
- [ ] More than half show the app in real use (not splash/login/title art)
- [ ] First 1-3 communicate the core value (they show in search)
- [ ] One benefit per screenshot, strongest first, tells a story
- [ ] Overlay text is a short phrase that enhances (not narrates) the visual; app UI not obscured
- [ ] Dark Mode shown at least once if supported
- [ ] Localized text per supported language
- [ ] IAP/extra purchase items disclosed if featured (2.3.2)

## App previews
- [ ] Screen capture of the real app only (2.3.4)
- [ ] First seconds lead with value; few cuts, slow readable pacing
- [ ] Works fully muted; audio (if any) is a gentle loop, no sudden loud moments
- [ ] Loops without a visible jump
- [ ] Poster frame chosen and compelling
- [ ] Beginning / middle / end

## Icon
- [ ] Simple, memorable, no excess detail; legible small
- [ ] Layered icon from Icon Composer (Liquid Glass) where possible
- [ ] Alternate/Watch/small icons consistent with the main icon

## Header / search creative / In-App Events (if used)
- [ ] Single clear idea; first-time-visitor focus
- [ ] Within template safe area; tested via ASC Preview
- [ ] Search asset: purpose obvious, real interface/content/gameplay
- [ ] IAE: both 16:9 card and 9:16 details made, visually continuous, doesn't duplicate badge text

## Copy
- [ ] Name <=30, subtitle <=30 (no "best", no other app names), promo text <=170
- [ ] Keywords <=100, comma-separated no spaces, no repeats/plurals/"app"/category/trademarks
- [ ] Description first sentence strong; no prices; accolades last
- [ ] What's New describes significant changes (2.3.12)

## Final
- [ ] Previewed in App Store Connect Preview tool
