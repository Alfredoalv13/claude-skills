# app-store-assets

Create, review and validate Apple App Store assets (icon, screenshots, previews, copy) against Apple's rules to avoid rejection.

**Use it when:** Preparing an iOS/macOS App Store listing.

**Notes:** `scripts/validate_assets.py` checks sizes and formats. Re-verify Apple's current specs before submitting.

## Install

```bash
cp -R app-store-assets ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
