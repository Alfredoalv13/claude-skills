# seo-geo-blog-engine

Research keywords, write answer-first articles with FAQ and schema, and publish only after your approval, built to rank on Google and get cited by AI assistants.

**Use it when:** You want a repeatable blog pipeline for search and AI-citation traffic.

**Notes:** Creates a small `blog-engine/` folder for your brand notes and keyword list. Never publishes without explicit approval.

## Install

```bash
cp -R seo-geo-blog-engine ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
