# community-listening-engagement

Find real conversations on Reddit, LinkedIn and X, learn the audience's pain points and language, and draft value-first replies for you to review and post yourself.

**Use it when:** You want audience insight and genuine community presence without spam.

**Notes:** Draft-only: a human reviews and posts. Respects each platform's terms.

## Install

```bash
cp -R community-listening-engagement ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
