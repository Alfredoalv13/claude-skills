# content-autoresearch

A measured experiment loop for social content: baseline, change one variable, publish, measure, and keep only changes with clear lift.

**Use it when:** You want data, not guesses, about what content works.

**Notes:** Default rule: lift of at least 1.30x with 15+ posts per arm over 14 days; change it once, in writing, before you start. It never posts for you.

## Install

```bash
cp -R content-autoresearch ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
