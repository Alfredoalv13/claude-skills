# hormozi-content-framework

A value-first content checklist and rules inspired by Alex Hormozi's $100M Offers and $100M Leads, paraphrased, not a substitute for the books.

**Use it when:** Writing posts, emails and lead magnets for your brand.

**Notes:** Replace the `{{brand}}`, `{{audience}}`, `{{product}}`, `{{link}}` placeholders. Not affiliated with or endorsed by the author.

## Install

```bash
cp -R hormozi-content-framework ~/.claude/skills/
```

Restart Claude Code; the skill triggers from its `description`. License: MIT (see repo root).
